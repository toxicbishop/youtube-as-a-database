# YouTubeDB REST API Specification

## 1. Overview

YouTubeDB provides an asynchronous REST API built with FastAPI. It serves the web UI, processes database lookups, accepts queued updates, and triggers append-only video segment flushes.

- **Base URL:** `http://localhost:8000`
- **Interactive Documentation:** `http://localhost:8000/docs` (Swagger UI) / `http://localhost:8000/redoc`

---

## 2. Endpoints

### 2.1 Fetch Record

```http
GET /customer/{id}
```

Retrieves a single customer record by its numeric identifier.

#### Parameters:
| Name | In | Type | Required | Description |
|---|---|---|---|---|
| `id` | path | `integer` | Yes | Numeric record ID (must be $\ge 1$) |

#### Response (200 OK):
```json
{
  "customer": {
    "id": 7,
    "name": "Hana Khan",
    "email": "hana.khan7@example.com",
    "phone": "+1-555-0124",
    "city": "Lisbon",
    "plan": "free",
    "balance": 3306.32,
    "joined": "2019-02-28",
    "note": "FAKE DATA - generated by seed.py"
  },
  "meta": {
    "segment": "seg_0001",
    "source": "youtube",
    "frames": [0, 1],
    "frames_scanned": 51,
    "rs_corrected_bytes": 4,
    "elapsed_ms": 6420.5
  }
}
```

#### Error Responses:
- **`404 Not Found`**: The record ID does not exist in the index.
  ```json
  { "detail": "Record 999 not found" }
  ```
- **`503 Service Unavailable`**: The record exists in the index, but its video segment frames could not be fetched or decoded (e.g. YouTube stream down or corrupted).
  ```json
  { "detail": "frame(s) [0, 1] missing or corrupt" }
  ```
- **`422 Unprocessable Entity`**: Invalid parameter (e.g. `id < 1`).

### 2.2 Stage Update

```http
PUT /customer/{id}
```

Queues an update for a record. Because YouTube videos are immutable, the change is held in the pending queue until the next flush.

#### Parameters:
| Name | In | Type | Required | Description |
|---|---|---|---|---|
| `id` | path | `integer` | Yes | Numeric record ID |

#### Request Body (`application/json`):
```json
{
  "name": "Hana Khan-Updated",
  "plan": "enterprise (lol)",
  "balance": 9999.00
}
```
*Note: The serialized JSON payload must not exceed 510 bytes.*

#### Response (202 Accepted):
```json
{
  "status": "queued",
  "id": 7,
  "pending": 1
}
```

#### Error Responses:
- **`422 Unprocessable Entity`**: Record exceeds the maximum 510-byte limit.

---

### 2.3 Flush Updates

```http
POST /flush
```

Encodes all queued updates into a new video segment, writes the video to disk, and repoints the index to the new segment.

#### Response (200 OK):
```json
{
  "status": "flushed",
  "segment": "seg_0002",
  "records_written": 1,
  "frames": 8,
  "video_path": "data/videos/seg_0002.mp4"
}
```
*If no updates are pending:*
```json
{
  "status": "nothing pending"
}
```

---

### 2.4 Index Statistics

```http
GET /stats
```

Returns aggregate metadata about the database.

#### Response (200 OK):
```json
{
  "records": 50,
  "segments": 1,
  "pending_updates": 0,
  "storage_source": "youtube"
}
```

### 2.5 Web Interface

```http
GET /
```

Serves the standalone [static/index.html](../static/index.html) single-page application with the live TV static animation and query console.
